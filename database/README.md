# oneSub Database Setup

## Database Name

`onesub`

## Requirements

* MySQL 8.0+
* MySQL Workbench (optional)

## Setup Steps

1. Open MySQL Workbench.
2. Run `onesub.sql` to create the database and tables.
3. Run `sample_data.sql` to insert default categories and demo subscriptions.

## Tables

* users
* categories
* subscriptions
